01 — Computer vision · edge AI

Prahari — The Watchman

YOLOv8 · DeepSORT · Flask · SQLite · Groq API · Apple MPS

An edge-optimized surveillance pipeline built to run entirely on 8GB of RAM. YOLOv8n detects and DeepSORT tracks every person and object on my Mac's own GPU; SQLite logs what it sees; and a Groq-powered LLM bridge lets me ask the log plain questions — "did anyone leave a bag unattended?" — instead of scrubbing through footage myself.

  • Hybrid edge-cloud architecture designed around 8GB RAM hardware constraints
  • Persistent multi-object tracking with IDs held across frames
  • Loitering and unattended-object anomaly detection, spatial + temporal
  • Duplicate-write guard keeps the event log clean under continuous tracking

02 — Real-time systems · WebRTC

Recall — AI Meeting Intelligence

WebRTC · Socket.io · Node.js · Firebase · Web Speech API

A peer-to-peer video calling app where the server only ever brokers a handshake. Once two browsers agree on a path, video and audio flow directly between them — the backend just relays SDP offers and ICE candidates. On top, live speech-to-text turns every call into a searchable transcript, with a summary waiting the moment the meeting ends.

  • Signaling-only backend: media never touches the server
  • Live transcription via the Web Speech API, extractive auto-summaries
  • Firebase Authentication with a full meeting-history dashboard
  • Best supported in Chrome — documented, not hidden
